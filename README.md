对CL330控制器进行设置
runmode：仅保留 常亮=1、呼吸=2、闪烁=3（删除旧的 STOP/关闭线圈逻辑）
color：仅保留 红=1、绿=2、蓝=3、黄=4
LED 帧固定为 功能码 0x06（写单寄存器），寄存器地址 2199，写入值按模式基址 + 颜色偏移：
模式	红	绿	蓝	黄
常亮	2010	2011	2012	2013
呼吸	2020	2021	2022	2023
闪烁	2030	2031	2032	2033
超出上述模式/颜色的指令（如 runmode=0、紫/白等颜色）返回空并告警忽略——新协议未定义它们的写入值，且 robot_ctrol_node 正常运行时只发布这三种模式×四种颜色。
